# Dunford-Style Positioning Reference

## Core Principle

Positioning is the deliberate act of defining how a product is the best choice for a specific set of customers versus alternatives, in a market context that makes that value obvious.

## Component Model

Use this component sequence:

1. Competitive alternatives (including status quo)
2. Unique/differentiated capabilities
3. Value themes (customer outcomes)
4. Best-fit customer segments
5. Market category (frame of reference)

Treat these as interdependent decisions: changing one can require revisiting others.

## Workshop Facilitation Guide

### Prep

- Gather 5–10 recent deal stories (wins + losses).
- Collect top objections from sales and support.
- Gather competitive comparisons used in active deals.
- Define the scope: exact product boundary and geography.

### Session 1: Alternatives + Differentiation

- Ask: “If we didn’t exist, what would this customer do?”
- Distinguish direct competitors from status-quo behavior.
- Draft differentiated capabilities with concrete proof.

### Session 2: Value + Segment

- Translate each capability to measurable outcomes.
- Match outcomes to segments/personas where pain is acute.
- Prioritize 1 primary segment and 1–2 secondary segments.

### Session 3: Category + Narrative

- Compare 2–4 market category options.
- Select category that minimizes explanation burden while highlighting strengths.
- Draft and test core narrative for clarity and credibility.

## Validation Checklist

- Can a prospect explain what we do in one sentence after hearing our intro?
- Do top 3 objections drop when new messaging is used?
- Do reps use the new narrative without heavy coaching?
- Does win-rate improve in the primary segment?
- Are disqualification decisions faster for low-fit prospects?

## Practical Heuristics

- Use plain language first; polish later.
- Prefer narrow clarity over broad ambiguity.
- If claims require long explanation, category is likely misframed.
- If value sounds generic, differentiation is probably weak.
- If every segment appears “ideal,” segmentation is insufficiently specific.

## Deliverables Checklist

- Positioning one-pager
- Messaging hierarchy doc
- Sales story/pitch narrative v1
- Objection handling map
- Rollout plan across website, collateral, demos, and sales enablement

## Research Notes (Source Grounding)

This skill is grounded in publicly described ideas from April Dunford’s positioning material, including:

- Emphasis that positioning is a deliberate strategic exercise, not a Mad-Libs statement.
- Use of component-based workflow centered on alternatives, differentiation, value, segment, and market context/category.
- Need for iterative validation as markets and buyer context evolve.
