# April Dunford Positioning

Run a rigorous positioning workflow that produces clear decisions, not vague taglines. Prioritize evidence from real customer wins/losses and competitive context.

## Quick Workflow

1. **Set context and objective**
   - Confirm product scope (company, product line, or feature set).
   - Confirm objective: new positioning, repositioning, category change, launch narrative, sales enablement, or messaging refresh.
   - Capture constraints (timeline, stakeholders, markets, regulatory limits, brand constraints).

2. **Map competitive alternatives**
   - Identify what customers do *today* without this product (including status quo/manual workflows).
   - Split alternatives by segment/persona if needed.
   - Capture decision criteria buyers use to evaluate options.

3. **Extract differentiated capabilities**
   - List capabilities that are truly difficult for alternatives to match.
   - Exclude generic table-stakes features.
   - Keep capabilities concrete and verifiable.

4. **Translate capabilities into value themes**
   - Convert each capability into customer outcomes (time saved, risk reduced, revenue impact, speed, confidence, compliance, etc.).
   - Tie value to a specific buyer/job where possible.

5. **Identify best-fit customer segments**
   - Find segments where value is strongest and alternatives are weakest.
   - Rank segments by pain intensity, willingness to buy, and ability to reach.

6. **Choose market category (frame of reference)**
   - Pick the category/context that makes differentiated value easiest to understand.
   - Evaluate category options: familiar category, adjacent category, or new category.
   - Explicitly document tradeoffs of each option.

7. **Build positioning outputs**
   - Positioning core: segment, alternatives, differentiated capabilities, value themes, category.
   - Messaging hierarchy: one-liner, value pillars, persona-specific proof points.
   - Sales narrative starter: problem → old way limits → new approach → proof.

8. **Pressure test and iterate**
   - Test with sales calls, discovery calls, demos, and win/loss feedback.
   - Log confusion points and objections.
   - Revise category, segment focus, or value language as evidence accumulates.

## Interview & Evidence Rules

- Prefer evidence over internal opinion.
- Pull examples from:
  - Recent closed-won and closed-lost deals.
  - Support/escalation patterns.
  - Customer interviews and call transcripts.
  - Competitive displacement stories.
- When evidence is weak, flag assumptions clearly and propose validation experiments.

## Output Format (Default)

When asked to execute this skill, return sections in this order:

1. **Positioning Decision Summary** (short, executive-ready)
2. **Positioning Components Table**
   - Competitive alternatives
   - Differentiated capabilities
   - Value themes
   - Best-fit segment
   - Market category
3. **Messaging Architecture**
   - Core message
   - 3–5 value pillars
   - Persona adaptations
4. **Sales Narrative Skeleton**
5. **Risks, Assumptions, and Validation Plan**
6. **30/60/90-Day Rollout Plan**

## Anti-Patterns to Avoid

- Writing slogans before positioning decisions are made.
- Treating positioning as a one-time copywriting task.
- Keeping historical category baggage when customer value now fits elsewhere.
- Using broad, non-falsifiable claims (“easy,” “best,” “innovative”) without proof.
- Over-targeting too many segments at once.

## Adaptation Modes

Choose one mode before starting, then state it explicitly.

- **Fast Draft (60–90 min):** limited evidence, hypothesis-led, useful for early-stage teams.
- **Standard Sprint (1–2 weeks):** interview-guided, enough rigor for GTM updates.
- **Deep Reposition (2–6 weeks):** multi-segment, win/loss analysis, category decision with rollout plan.
